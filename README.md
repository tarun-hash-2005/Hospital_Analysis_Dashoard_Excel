**Hospital_Analysis_Dashboard_Excel**

## 🎯 Project Objective

The objective of this project is to transform raw hospital data into an interactive dashboard that provides valuable insights into hospital performance, patient trends, departmental revenue, and operational efficiency.

This dashboard enables users to:

- Monitor Total Revenue
- Track Total Diagnoses
- Analyze Patient Admissions
- Compare Department-wise Revenue
- Monitor Patient Gender Distribution
- Track Monthly Admissions & Discharges
- Analyze Payment Status
- Filter reports dynamically using slicers
